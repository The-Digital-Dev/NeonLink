# Code of conduct

NeonLink follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give and accept constructive feedback,
and focus on what is best for the project and its users. Harassment, personal attacks, sexualised
language or imagery, and publishing others' private information are not acceptable in issues,
pull requests, discussions or any other project space.

Report unacceptable behaviour privately to the maintainers through GitHub (for example by opening a
private security advisory if no other private channel suits). Reports are handled confidentially.
Maintainers may remove contributions and restrict participation of anyone who breaks this code.
